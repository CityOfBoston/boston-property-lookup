EGIS ArcGIS layer explorer

Mirrors the MapServer layer queries used in EGISClient.ts (dev/prod base URLs from functions env). Defaults: environment dev, fiscal year and quarter = current Boston FY period, parcel empty. Fill parcel ID, then Fetch all layers. If the browser blocks cross-origin requests, copy the curl and run in a terminal.

Fiscal year/quarter follows getFiscalYearAndQuarter: before July 1 → current calendar year + Q3; on/after July 1 → next calendar year + Q1.

CORS: responses load in-page only if gisportal.boston.gov allows this origin (often file:// is blocked; open via a static server or use curl from the page).
